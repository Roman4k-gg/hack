# Инструменты для модели

Описания, которые видит модель, — в `description` файлов [`../contracts/mcp/`](../contracts/mcp)
(генерируются из `ai/app/agent/tools.py`). Здесь — когда агент должен их выбирать.

| Пользователь пишет | Инструмент | Аргументы |
|---|---|---|
| «Что делать дальше?», «какой у меня прогресс», «что на этой неделе» | `get_onboarding_plan` | — |
| «Кто я?», «моя команда», «мой наставник» | `get_my_profile` | — |
| Любой вопрос о команде, процессах, инструментах | `search_knowledge` | `query` — вопрос целиком |
| «Как получить доступ к Jira?» | `search_knowledge` | это вопрос, **не** действие |
| «Хочу отгул в пятницу», «отпуск с 20 по 24 ноября», «заболел» | `preview_absence_request` | `date_from`, `date_to` (ГГГГ-ММ-ДД), `absence_type`: `day_off` / `vacation` / `sick_leave` |
| «Оформи доступы», «пакет доступов стажёра» | `preview_access_bundle` | `bundle="intern"` |
| Ответа нет в базе; «передай наставнику», «спроси у наставника» | `preview_handoff` | `question` — вопрос пользователя, `context` — что уже искал |
| «Да», «подтверждаю», «отправляй» — после черновика | `create_absence_request` / `create_access_requests` / `create_handoff` | без аргументов, агент подставит черновик |
| «Нет», «отмена», «передумал» — после черновика | — | ответить, что заявка не отправлена |
| «Мои заявки», «что с заявкой» | `get_my_requests` | — |
| «Привет» | — | короткое приветствие и что умеет |

## Ошибки инструментов

| Код | Что сказать пользователю |
|---|---|
| `FORBIDDEN` | Действие недоступно для его роли; если нужно — к наставнику |
| `NOT_FOUND` | Не нашлось; предложить уточнить. Для `create_handoff` — передать не получилось, написать наставнику самому |
| `VALIDATION_ERROR` | Что именно не так (текст из `message`) и как исправить |
| `CONFIRMATION_REQUIRED` | Сначала покажу черновик, отправлю после подтверждения |
| `INJECTION_SUSPECTED` | В документе была подозрительная инструкция, ничего не выполнял |
| `TIMEOUT`, `UPSTREAM_ERROR` | Сервис недоступен, попробовать позже; черновик сохранён |
